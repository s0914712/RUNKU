## 🔍 星獸偵探社（故事解謎系列）

姊妹各有一本專屬案件簿，共 8 件委託。每一件委託的流程都一樣：

1. **讀委託** — 看看現場發生了什麼事。
2. **蒐證** — 現場有 5 個線索，每個線索背後是一道單字題，答對才會看到線索內容，並自動記進「偵探筆記本」。
3. **指認** — 五條線索到齊後，把筆記本對照三位嫌疑星獸的特徵，只有一位完全符合。
4. **結案** — 指認正確就揭曉真相，該位星獸會加入偵探社成為你的夥伴卡。

| 案件簿 | 四件委託 | 使用單字 |
|--------|---------|---------|
| 👩 **蒼藍檔案**（姊姊） | 消失的巧克力 → 教室裡的怪聲 → 被打斷的排練 → 星語鐘塔的最後謎題 | 食物 → 學校 → 動作 → 生活用語 |
| 👧 **曙光檔案**（妹妹） | 不見的彩虹風箏 → 動物園的悄悄話 → 音樂會走音之謎 → 數字城堡的暗號 | 物品 → 動物 → 樂器與職業 → 數字與身體部位 |

每件委託的 5 道題各用一種題型：**看中文選英文**、**看英文選中文**、**聽發音選英文**、**字母拼字**、**句子克漏字**，所以同一份單字會用五種角度各練一次。

答錯不會失敗也不會扣命，只會少一點分數；卡住的時候可以按「💡 提示」刪掉一個錯的選項或補一格字母。破解一件委託才會解鎖下一件，進度分姊妹各自存在瀏覽器中。

> 每個案件的線索都是**可以真的推理出來的**——例如「犯人飛得到雲那麼高」加上「身上會掉花瓣」，就只剩下有花瓣翅膀的蘭翼符合。三位嫌疑星獸的特徵互相排除，不是猜的。

## ✨ 特色

- 🔊 **真人發音**：使用瀏覽器 Web Speech API 唸出英文（速度放慢，適合小朋友）
- ⭐ **星星獎勵系統**：答對累積星星，激勵持續練習
- 📊 **熟練度追蹤**：每個單字依答對／答錯次數顯示 0～3 顆星
- 🗂️ **七大主題**：基礎用語、動物、生活物品、職業人物、交通與樂器、數字 1-10、身體部位
- 💾 **自動存檔**：進度存在瀏覽器 LocalStorage，關掉再打開還在
- 📱 **手機優先**：大按鈕、大字體，平板手機都好按
- 🎉 **即時回饋**：音效、動畫、彩帶慶祝

## 🔨 打地鼠設定

進入打地鼠、選完主題後，可以在同一個畫面調整：

**⏱️ 圖卡停留時間（1～10 秒）**
用滑桿或 −／＋ 按鈕調整地鼠停在畫面上的秒數。剛開始背單字建議 8～10 秒，熟了之後再往下調，變成反應力訓練。

**🎚️ 難度**

| 難度 | 地鼠數量 | 題目提示 | 每次敲中 |
|------|---------|---------|---------|
| ⭐ 簡單 | 3 個 | 中文 + 圖示 | 10 顆星 |
| ⭐⭐ 普通 | 4 個 | 中文 + 圖示 | 15 顆星 |
| ⭐⭐⭐ 困難 | 6 個 | 只有中文，沒有圖示 | 22 顆星 |

設定會自動記住，下次打開還是同樣的設定；最佳紀錄依難度分開記錄，不同難度不互相比較。

## 🚀 使用方式

### 直接遊玩
開啟 [https://s0914712.github.io/RUNKU/](https://s0914712.github.io/RUNKU/) 即可，不需要安裝任何東西。

### 本機執行
```bash
git clone https://github.com/s0914712/RUNKU.git
cd RUNKU
cd frontend
npm install
npm run dev
```

終端機會顯示本機網址，通常是 `http://localhost:5173/`。建立正式版本可執行 `npm run build`，輸出會放在 `frontend/dist/`。

## ✏️ 更換單字

要換成新一課的單字時，編輯對應的 JSON 單字檔即可：

- 姊姊：`data/vocabulary-jie.json`
- 妹妹：`data/vocabulary.json`

React 版本會由 `frontend/src/context/ProfileContext.jsx` 自動載入這兩份單字庫。每個單字的基本格式如下：

```js
{ "id": 59, "en": "apple", "zh": "蘋果", "cat": "things", "emoji": "🍎" }
```

如需增加人物或修改單字分類，可編輯 `frontend/src/context/ProfileContext.jsx`。
